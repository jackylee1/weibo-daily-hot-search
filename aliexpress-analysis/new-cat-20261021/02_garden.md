# 02 花园滤芯 — 三平台是三种产品（本类最重要发现）

| 形态 | 是什么 | 谁在卖 | 能否互为同款 |
|---|---|---|---|
| 直通碳滤 Inline Carbon | 3/4"软管串联，GAC+KDF，除氯/异味/沉积，浇花/RV/洗车/给泳池注水 | 亚马逊头部 | **目标款** |
| 灌溉网滤 Mesh Strainer | 泵入口不锈钢网，拦颗粒，农业滴灌 | 速卖通头部 | 否，功能完全不同 |
| 全屋前置 | 家用自来水前置（云米/美的） | 拼多多核到的唯一一条 | 否 |

## 亚马逊（间接核验）
### Camco TastePURE 40043（类目标杆）
- 亚马逊约 $17单支 / $25双支（对比站转述亚马逊价）；近 50,000 亚马逊评价，4.5星
- 20μm，GAC+KDF 6级，NSF/ANSI 42/53（品牌宣称，引用时需核证书），带软管保护弯头，约3月/2,000gal换
- 购买链接入口（测评汇总页，非亚马逊直链）：https://top5best.com/garden-hose-filter

### AQUA CREST RV Inline 2-Pack
- 亚马逊约 $9单支 / $18双支（实测站转述）；被指与 Amazon Basics 直通滤同款；NSF 宣称，2支+弯头

### POOLPURE Garden Hose End Pre-Filter / AQUACREST Garden for Plants
- 同在亚马逊花园榜头部：前者主打给泳池/SPA注水（8,000gal，3/4"），后者主打植物（降氯/钙）。这两个细分词值得做标题：`garden hose filter for plants` / `for filling pool hot tub`。

## 拼多多
- 花园软管专用滤：Bing/Google/360/搜狗均无可核实商品页。
- 唯一核实：云米前置过滤器 Super 952711935079 https://m.pinduoduo.com/m_goods-detail?goods_id=952711935079 已拼5,000+，价首位5（500元档，具体未核实）— 这是全屋前置，不是花园款。
- 结论：拼多多不能作花园直通碳滤的已核实货源，货源需另找（1688未在本任务授权内展开，留待用户指令）。

## 图文分析
亚马逊直通款主图公式：蓝色/白色圆柱本体斜45°+弯头配件同框+NSF徽章+场景小图（RV/浇花/洗车）。速卖通网滤主图：零件平铺+尺寸标注线。你若做直通款，图按亚马逊公式，但徽章只能用自有证书，没有就留空写 media 成分，不要借 Camco 的 NSF。
